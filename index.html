Network types in a grid and a form

IPv4, IPv6, CIDR, MAC and VLAN each sort, filter and validate as the address they are, not as text. The grid and the form share one parser, so a value is accepted or refused the same way in a cell as in a field.

Code on GitHub Lattice Grid column types

Inventory

Sort the IPv4 column: 192.0.2.9 comes before 192.0.2.10. Filter MAC by 1a2b, whatever spelling is shown.

Selected row

Type a MAC as 00-1A-2B-3C-4D-5E or 001a.2b3c.4d5e; it is stored with colons. A bad IPv4 or VLAN 5000 is refused.

What the row holds

Read-only. Text is stored: dotted IPv4, a /24 network, a colon MAC. The subnet column keeps the network, so 10.1.2.3/24 becomes 10.1.2.0/24.
